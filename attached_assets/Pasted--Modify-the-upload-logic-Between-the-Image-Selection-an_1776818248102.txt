"Add a new optional workflow to the application for GCP-based volume measurement.
1.	Add a file upload button specifically for a gcp_list.txt file.
The Sample GCP File (gcp_list.txt)
Since you are using a 1-meter ruler for internal research without GPS, your sample file should use a Local Coordinate System. Replit should generate this sample file for users to download as a template.
File Content:
Plaintext
WGS84 UTM 31N
0 0 0 0 0 "mark_start"
1 0 0 0 0 "mark_end"
•	Row 1: The coordinate system (using WGS84 UTM is a standard placeholder for local scaling).
•	Rows 2-3: Coordinates for the start (0,0,0) and end (1,0,0) of your 1-meter ruler.
•	The Columns: X Y Z Pixel_X Pixel_Y "Label". (We leave Pixel X/Y as 0 because you will fill them in using the WebODM interface).

2.	Update the WebODM API request to include this file in the files payload under the key 'gcp'.
3.	Add a logic switch: If a GCP file is uploaded, set the task option dmanual-gcp to true. This tells WebODM to pause and wait for the user to tag the markers in the web interface.
4.	After the upload is successful, provide a direct link to the WebODM task URL (e.g., https://webodm.net/task/{id}/gcp/) so the user can open the GCP interface and start tagging."
Once the API starts the task, the user must follow these steps (your Replit app should display these as instructions):
1.	Open Task: Click the link generated by the app to open the WebODM GCP Editor.
2.	Select Point: Select mark_start from the list on the left.
3.	Find Photo: Click a photo where the 0cm end of the ruler is clear.
4.	Tag: Click the exact pixel of the 0cm mark.
5.	Repeat: Do this for mark_end (the 100cm mark).
6.	Save & Process: Click "Submit" or "Save" in the WebODM interface. The engine will now restart and calculate your volume based on that 1-meter scale.
