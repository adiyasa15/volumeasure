Master Prompt: AI Stockpile Volume Measurement App
Role: Expert Full-stack Developer & Geospatial Engineer.
Objective: Build a web application to measure stockpile volumes (Sand, Soil, Coal) using WebODM Lightning API.
Core Tech Stack:
•	Frontend: React (Vite), Tailwind CSS, Lucide Icons.
•	Authentication: Google OAuth (Supabase Auth or Firebase).
•	Database: Supabase (to store job history, volume results, and image URLs).
•	Backend/API: Integration with WebODM Lightning API.
Workflow Requirements:
1.	User Authentication: Implement "Login with Google". Secure the dashboard so only logged-in users can upload and view data.
2.	Image Upload & Quality Filter:
o	Create a drag-and-drop upload zone for Drone (JPG/TIFF), Smartphone, and DSLR photos.
o	Add a pre-processing step to filter out blurry images or non-geotagged images (if drone) before sending to API.
3.	WebODM Lightning Integration:
o	Connect to https://webodm.net.
o	Automatically create a "Task" upon upload.
o	Crucial: Use API flags for automatic refinement: --auto-boundary, --dsm, --orthophoto, and --feature-quality high.
4.	Automatic Polygon & Volume Calculation:
o	Once the WebODM task is "Completed", automatically fetch the area_volume result.
o	The app must trigger a volume calculation request using the auto-boundary polygon generated by WebODM.
5.	Dashboard & Visualization:
o	Display a list of previous measurements in a clean table/grid.
o	Show the refined Orthophoto image and the calculated Volume ($m^3$) clearly.
o	Include metadata: Material type (User selects: Sand/Soil/Coal), Date, and Precision level.
UI/UX Instructions:
•	Use a professional "Industrial Dashboard" theme (Dark mode preferred).
•	Add a progress bar to show WebODM processing status (Queued -> Running -> Completed).
•	Display a simple map view (using Leaflet or Mapbox) to show the location of the stockpile.
Constraint:
•	Secure all API Keys in environment variables.
•	Ensure the app can handle multiple image uploads (Batch upload).
